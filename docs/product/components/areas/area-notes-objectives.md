# Collection Area: Notes And Objectives

## Parent Page

`docs/product/pages/10-collection-areas.md`

## Purpose

Give the user a place to think inside an area: notes, objectives when relevant,
ideas, current context, and what is going on.

## Wanted State

The component should support:

- Optional objectives/goals.
- Free-form notes.
- Ideas.
- Current context / what is going on.
- Optional dated updates later.

## Acceptance Criteria

- Notes are saved reliably.
- Objectives are optional, because some areas are simple genres/media types.
- Long text remains comfortable to edit.
- Empty notes do not make the area feel broken.
