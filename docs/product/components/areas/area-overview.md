# Collection Area: Overview

## Parent Page

`docs/product/pages/10-collection-areas.md`

## Purpose

Show the high-level state of a focused collection area, such as romance,
western, polar/crime, manga, bande dessinee, magazine, programming, or language
learning.

## Wanted State

The overview should show:

- Area title/name.
- Area kind: genre, media type, subject, learning project, research project, or
  custom.
- Description.
- Status: planned, active, paused, completed, reference.
- Count of owned books.
- Count of wanted/not-owned books.
- Count by level when relevant: beginner, intermediate, advanced, reference,
  unknown.
- High-priority books still unread or not owned.

## Acceptance Criteria

- User can immediately understand what the area is about.
- Genre/media areas work without forcing learning objectives.
- Learning/project areas can show objectives and progress.
- Owned vs missing books are visible.
