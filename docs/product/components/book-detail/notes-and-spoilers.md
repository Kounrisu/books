# Book Detail: Notes And Spoilers

## Parent Page

`docs/product/pages/04-book-detail.md`

## Purpose

Let the user store and read different kinds of text about a book without
confusing public-style descriptions, spoilers, and personal notes.

## Current State

There is no dedicated book detail page yet.

## Wanted State

The detail page should separate:

- Description: spoiler-free summary/back-cover style text.
- Spoiler notes: private plot/ending/summary notes that may reveal the book.
- Personal notes: loose thoughts, quotes, context, or reminders.
- Personal review: structured opinion/review.

## Acceptance Criteria

- Spoiler notes are hidden/collapsed by default or clearly marked.
- Description remains easy to read without exposing spoilers.
- Empty sections are not noisy.
- Editing entry points are clear.

## UX Notes

Phase 1 can use expansion panels or sections. Phase 2 can add more refined
typography and reveal interactions.
