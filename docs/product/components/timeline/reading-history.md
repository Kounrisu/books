# Timeline: Reading History

## Parent Page

`docs/product/pages/11-timeline.md`

## Purpose

Track when the user started, finished, abandoned, or referenced a book.

## Wanted State

Reading history should support:

- Date started.
- Date finished.
- Reading status.
- Optional notes for that reading period.
- Multiple reading events for rereads.

## Acceptance Criteria

- A book can have more than one reading history entry.
- Reading history appears on the timeline and book detail page.
- Current `readingStatus`, `dateStarted`, and `dateFinished` can be derived
  from or synchronized with reading history.
