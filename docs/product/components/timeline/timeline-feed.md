# Timeline: Feed

## Parent Page

`docs/product/pages/11-timeline.md`

## Purpose

Render a chronological feed of reading, acquisition, rental, borrowing, lending,
publication, print/edition, original-work, and historical/setting events.

## Wanted State

The feed should support:

- Chronological ordering.
- Multiple timeline modes: personal, publication, original/historical,
  print/edition, combined.
- Event type filters.
- Date range filters.
- Book/area/source filters.
- Links to book detail pages.
- Clear icons/labels for event types.

## Event Types

- Reading started.
- Reading finished.
- Acquired/bought/gifted/inherited.
- Borrowed externally.
- External due date.
- Returned to external source.
- Lent to someone.
- Returned by borrower.
- Marked lost.
- Marked found.
- Metadata imported/reviewed.
- Edition published.
- Physical copy printed/released.
- Original work written/composed.
- Historical/setting period.

## Acceptance Criteria

- User can answer "what did I read and when?"
- User can answer "when did I buy, borrow, rent, return, or lend this?"
- User can answer "when was this edition published or printed?"
- User can answer "where does this work sit historically?"
- Approximate, partial, and unknown dates are clearly labeled.
- Events link back to the relevant book when available.
- No-results and empty states are clear.
